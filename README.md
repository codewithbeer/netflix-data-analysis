# Netflix Data Analysis

## Project Overview
Analysis of Netflix movies and TV shows using Python and Power BI.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI

## Analysis
- Movies vs TV Shows
- Content added by year
- Content by country
- Rating distribution
- Release year analysis
## Business Insights

* **2019 recorded the highest number of content additions** on Netflix, with Movies accounting for approximately **71%** and TV Shows making up **29.3%** of the content added that year.

* The **United States contributed the highest amount of content** to Netflix, followed by **India**, making them major contributors to Netflix's content library.

* In India's content contribution, **Movies dominate significantly, accounting for approximately 92%**, while **TV Shows account for around 8.1%**.

* **International Movies** is the most common genre/category in the dataset, followed by **Drama**.

* Among TV Shows, **TV-MA is the most common rating**, indicating that a large portion of Netflix's TV content is targeted toward mature audiences.
